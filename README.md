# Kit del Médico de Primer Nivel

MVP frontend para un kit digital práctico dirigido a médicos jóvenes de primer nivel en México.

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS

## Objetivo del MVP

- Home mobile-first con navegación por herramientas.
- Primera herramienta funcional: Nota SOAP.
- Sin backend, autenticación ni persistencia en esta fase.

## Enfoque

No es un libro médico ni sustituye el criterio clínico. Es una herramienta práctica para ordenar información durante la consulta.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
